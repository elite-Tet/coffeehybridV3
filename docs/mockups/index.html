CoffeeHybrid: three homepage directions

All three use the same content and section order, so you compare design rather than copy. Each frame scrolls on its own.

A · Editorial minimal Open full page

Rationale
Treat the homepage like a well-set café menu: big serif type, a dot-leader price list, one photo, lots of air.
Signals to a hiring manager
Typographic discipline and hierarchy. Can make a page work through content and spacing instead of decoration.

B · Warm earthy Open full page

Rationale
Lead with the product’s real artifact, the pickup ticket, in an oat, espresso and leaf-green palette that evolves the work-in-progress redesign.
Signals to a hiring manager
Product thinking and iteration. Shows a design grown out of the app’s core flow, with a clear before and after.

C · Bold motion Open full page

Rationale
Make the order status itself the hero: a split-flap pickup board where codes flip to Ready, plus one scroll-linked progress line.
Signals to a hiring manager
Interaction craft with modern CSS (scroll-driven animation), with accessibility built in: a pause control and reduced-motion support.
